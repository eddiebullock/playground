# Cue

Realtime HUD for a video call or a video you are watching. Local only.

```
cd social_ai/cue/live
npm install
npm run dev
```

Open Chrome at http://127.0.0.1:5174/

Share a Meet/Zoom-in-browser **tab** and tick Share audio for turn-taking.
Sharing a Zoom desktop window usually gives video (eye contact, emotion)
without call audio.

Spec: `../docs/LIVE_BUILD.md`.
