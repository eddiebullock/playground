# Cue

Realtime HUD for a video file, a Zoom/Teams tab, or a window you share. Local only.

```
cd social_ai/cue/live
npm install
npm run dev
```

Open Chrome at http://127.0.0.1:5174/

- **Video file:** Open a video, or try the short sample. Play/pause/seek. The
  three tabs follow the recording as it plays.
- **Zoom / Teams:** Paste the invite, open it in Chrome, then share that
  *tab* and tick Share audio. Cue cannot attach to the desktop Zoom or
  Teams apps; a window share is usually picture without sound.
- **Any window:** Meet, a movie, or a desktop call window.

Spec: `../docs/LIVE_BUILD.md`.
